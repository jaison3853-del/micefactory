# Event inspiration visuals

Two original AI-generated concept visuals created on 20 October 2026 for the MICEFACTORY inspiration section. These are creative directions, not documentary photographs of client projects; the site labels them as concept visuals.

- `wedding`: native 1672 × 941, garden celebration at blue hour.
- `gala`: native 1672 × 940, corporate awards gala.

Each is encoded as WebP at 800 px, 1600 px and native width, without upscaling. Responsive `srcset` descriptors match the encoded widths. Images are lazy-loaded and served locally. The generator did not produce native 4K; native 4K source photographs are still needed to satisfy that resolution request. No image has been mislabeled as 4K.
